1. Project Title / Headline
GCC Tourism Analytics Dashboard: Arrivals, Revenue and Hotel Performance Across Six Countries (2018–2025)

2. Short Description / Purpose
An interactive Power BI dashboard that analyses tourism performance across six GCC countries from 2018 to 2025. It helps stakeholders see how tourist arrivals, tourism revenue and employment have grown. It also shows whether hotel supply is keeping up with demand, and who the visitors are and why they travel.

3. Tech Stack

Power BI Desktop: report design and interactive visuals
Power Query: data cleaning and transformation
DAX: calculated measures (weighted occupancy, ADR, RevPAR, YoY growth)
Data modelling: star schema with year and country dimension tables linked to fact tables
CSV: source file format

4. Data Source
source-https://www.kaggle.com/datasets/zkskhurram/gulf-countries-tourism-2018-q1-2026

5. Features / Highlights

Three analytical pages: Overview, Hotels and Visitors.
Overview: KPI cards for Total Arrivals (M), Tourism Revenue ($B), Weighted Occupancy %, Tourism Jobs (K) and Arrivals YoY %. A country-wise arrivals trend and a revenue comparison by country sit alongside them.
Hotel sector performance: Hotel capacity against occupancy, ADR and RevPAR trends, an occupancy vs ADR scatter plot by country, and a RevPAR matrix by year and country.
Visitor insights: Top 10 source markets, travel purpose breakdown, and tourism segment mix over time.
Interactive slicers for year and country, so every visual filters dynamically.
Weighted metrics that avoid the distortion of simple averages when comparing countries of different sizes.
